How this tracker works

  1. Pick a day and click the square to mark it as done.
  2. Your progress is stored in localStorage for this year.
  3. Use PNG/CSV export when you want to share or analyse the data.
  4. Optionally send a JSON backup to an Azure Function → Blob.

Architecture at a glance

Browser UI → Azure Function → Blob Storage

The frontend never talks directly to storage. The function validates input and writes one JSON blob per year, keeping the design simple and easy to reason about in interviews.

Privacy notes

By default everything stays in your browser. Cloud backup is manual on purpose, so you always know when data is leaving your device.
